# MyPortfolio/ポートフォリオサイト]設計書

## 1. 目的・コンセプト
- 自分の技術スタックを可視化
- 実績紹介

## 2. ターゲットユーザー
- 案件のクライアント
- 採用担当者（エンジニア・人事）
- 同じ技術に興味があるエンジニア仲間

## 3. サイトのゴール
- 「この技術が使えるんだな」と理解してもらう
- お問い合わせフォームから連絡をもらう
- GitHubやSNSをフォローしてもらう

## 4. コンテンツ（掲載内容）
- **自己紹介**: 経歴、スキルセット、学習中。の技術
- **制作物一覧**: プロジェクト概要、使用技術、担当範囲、苦労した点。
- **技術ブログ/記事**: 外部サービス（Qiita/Zenn）との連携。
- **SNS/連絡先**: GitHub, X(Twitter), メールフォーム。

## 5. 技術選定
- **Frontend**: HTML
> 将来的にはReact, Vue.jsを検討。日本企業に採用企業が多いため。
- **Styling**: Tailwind CSS(CDN)

- **Infrastructure/Hosting**: (例: Vercel / Cloudflare Pages)
> 将来的にはVercel, firebase
- **CMS (optional)**: (例: microCMS / Contentful)
> 将来的には(例: microCMS / Contentful)などのヘッドレスCMS導入を検討

## 6. サイトマップ（ページ構成）
- Home (トップページ)
- About (自分について)
- Works (制作物詳細ページ)
- Contact (お問い合わせ)

## 7. デザイン方針
- **トーン＆マナー**: シンプル、誠実、テック感、カラフル
- **参考サイト**: なし
- **カラーパレット**: #a78bfa
